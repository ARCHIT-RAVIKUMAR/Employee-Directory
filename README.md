# Staff directory

Small TypeScript project: a searchable staff directory.

- `src/types.ts` – the `Employee` interface and related types
- `src/data.ts` – the employee list
- `src/search.ts` – search and department filter
- `src/render.ts` – builds the table rows
- `src/main.ts` – connects the inputs to everything else

```
npm install
npm run build
npm run serve
```
